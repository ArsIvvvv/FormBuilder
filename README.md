# Конструктор форм откликов

Сервис, в котором менеджер собирает форму отклика в админке и публикует её по уникальной ссылке, а студент переходит по ссылке и заполняет её. Менеджер просматривает ответы в админке и может выгрузить их в CSV.

## Запуск

Нужен Node.js 20 или новее. Из корня репозитория:

```bash
npm install
npm start
```

После запуска:

- Админка: http://localhost:3000/admin (без авторизации)
- Публичная форма: ссылка вида `http://localhost:3000/f/<slug>`, её создаёт админка при публикации

Порт настраивается переменной окружения `PORT`:

```bash
PORT=4000 npm start          # Linux / macOS
$env:PORT=4000; npm start    # Windows PowerShell
```

Внешних зависимостей нет: сервис написан на встроенных модулях Node.js (`http`, `fs`, `crypto`), поэтому `npm install` ничего не скачивает и работает без интернета. Никаких API-ключей, облачных сервисов и отдельных СУБД не нужно.

## Ключевой сценарий

1. Откройте `/admin`, нажмите «Создать форму», задайте название и добавьте вопросы.
2. Нажмите «Сохранить и опубликовать»: появится уникальная ссылка с кнопкой «Копировать».
3. Откройте ссылку (например, в другой вкладке), заполните форму и отправьте.
4. В админке откройте «Ответы» нужной формы: там таблица с ответами и кнопка «Экспорт в CSV».

## Возможности

**Админка**
- список форм: название, статус (черновик / опубликована), дата создания, число ответов, действия (редактировать, опубликовать / снять с публикации, копировать ссылку, ответы, удалить);
- конструктор: название, описание, добавление / удаление / перестановка вопросов (кнопки ↑ ↓), предпросмотр;
- типы полей: короткий текст, длинный текст, число, email, выбор одного (radio), выбор нескольких (checkbox), выпадающий список, дата;
- у каждого вопроса: текст, подсказка, флаг «обязательное», варианты ответов (для типов с выбором);
- ответы: таблица (столбцы = вопросы, строки = отправки, дата и время), счётчик, экспорт в CSV.

**Публичная форма**
- рисуется по сохранённой схеме;
- проверка на клиенте и на сервере (обязательные поля, формат email, число, дата, допустимые варианты);
- страница «Спасибо, ответ отправлен»;
- если форма не найдена или не опубликована, показывается страница «Форма недоступна» (HTTP 404).

## API

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/api/forms` | список форм |
| POST | `/api/forms` | создать форму |
| GET | `/api/forms/:id` | получить форму |
| PUT | `/api/forms/:id` | обновить форму |
| DELETE | `/api/forms/:id` | удалить форму вместе с ответами |
| POST | `/api/forms/:id/publish` | опубликовать (генерирует slug, если его ещё нет) |
| POST | `/api/forms/:id/unpublish` | снять с публикации |
| GET | `/api/forms/:id/responses` | ответы (JSON) |
| GET | `/api/forms/:id/responses.csv` | экспорт в CSV |
| GET | `/api/public/forms/:slug` | схема опубликованной формы |
| POST | `/api/public/forms/:slug/responses` | отправка ответа студента |

Формат ошибок: `{ "error": "сообщение", "details": { ... } }`. Для ошибок валидации ответа `details.errors` содержит сообщения по id вопросов.

Пример схемы формы (`POST /api/forms`):

```json
{
  "title": "Отклик на стажировку",
  "description": "Расскажите о себе",
  "questions": [
    { "id": "name", "type": "text", "label": "Имя", "required": true },
    { "type": "radio", "label": "Язык", "options": ["JavaScript", "C#"] }
  ]
}
```

Типы: `text`, `textarea`, `number`, `email`, `radio`, `checkbox`, `select`, `date`.

## Где хранятся данные

В файле `data/db.json` внутри проекта. Папка и файл создаются автоматически при первом запуске. Запись атомарная (во временный файл, затем переименование), поэтому данные не повреждаются при остановке процесса. Чтобы начать с чистого листа, остановите сервис и удалите папку `data/`.

## Структура проекта

```
server.js              точка входа: HTTP-сервер, маршруты страниц и статики
src/
  api.js               REST API, сборка таблицы ответов и CSV
  storage.js           хранилище на JSON-файле
  validation.js        проверка схемы формы и ответов студента
  util.js              JSON-ответы, чтение тела запроса, HttpError
public/
  admin/               админка (одностраничное приложение)
  form/                страница публичной формы
  js/                  общие скрипты: DOM-помощники, рендер формы
  css/style.css        стили (без внешних библиотек и шрифтов)
test/smoke.js          сквозной тест сценария (npm test)
```

## Проверка

```bash
npm test
```

Тест сам поднимает сервер на свободном порту с временной папкой данных и проходит весь сценарий: создание формы, публикация, отправка ответа, просмотр, CSV, снятие с публикации, удаление.
